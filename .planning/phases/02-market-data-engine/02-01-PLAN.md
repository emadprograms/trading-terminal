# Plan: 02-01 - Historical Data Integration

## Goal
Replace the local SQLite-based historical data fetching with live REST API calls to Capital.com, ensuring charts populate immediately upon ticker selection.

## Context
Currently, `useChartData.ts` calls `fetchMarketData` in `src/lib/db.ts`, which queries a local database. We need to redirect this flow to the `MarketDataClient` created in 02-00.

## Implementation Details

### 1. Data Adapter (`src/lib/data-adapter.ts`)
Create a transformation layer to convert `CapitalCandle` responses into the internal `RawBar` format used by `lightweight-charts` and the rest of the app.
- **Bid/Ask Selection:** Since the API provides both, the adapter should default to `bid` for chart rendering (configurable).
- **Time Normalization:** Convert `snapshotTime` (ISO 8601) to the timestamp format expected by `RawBar`.

### 2. Update Data Fetching Logic (`src/lib/db.ts` or new service)
Refactor `fetchMarketData` and `fetchHistoricalChunk` to use the `MarketDataClient`.
- `fetchMarketData`: Now calls `MarketDataClient.fetchCandles` with the appropriate `resolution` and `max` count based on the requested date range.
- `fetchHistoricalChunk`: Implement pagination/windowing using the `from` and `to` parameters of the REST API to support infinite scroll.

### 3. Integration with `useChartData.ts`
- Ensure `useChartData` continues to work seamlessly with the new asynchronous API calls.
- Add error handling for API failures (e.g., invalid EPICs) to prevent chart crashes.

## Verification Plan

### Integration Tests (`tests/integration/market-data.test.ts`)
- **End-to-End Flow:** Mock the `/api/v1/prices/{epic}` endpoint and verify that calling `fetchMarketData` returns a correctly formatted `RawBar[]`.
- **Infinite Scroll:** Verify that calling `fetchHistoricalChunk` requests the correct time window from the API.

### Manual Validation
- Select a known EPIC (e.g., `SPY`) in the UI.
- Verify that the chart populates with historical candles.
- Scroll back in time to verify that additional chunks are fetched and appended correctly.
