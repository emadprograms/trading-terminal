  <name>Task 1: Define Trade Types</name>
  <files>src/types/trade.ts</files>
  <action>
    Create `src/types/trade.ts` and define the following interfaces based on Capital.com API specs (per RESEARCH.md):
    - `OrderType`: 'MARKET' | 'LIMIT' | 'STOP'.
    - `OrderDirection`: 'BUY' | 'SELL'.
    - `OrderStatus`: 'PENDING' | 'ACCEPTED' | 'REJECTED' | 'CANCELLED'.
    - `Order`: Represents a working or pending order (epic, size, level, type, direction, status, dealReference, etc.).
    - `Position`: Represents an active open trade (dealId, epic, size, entryPrice, etc.).
    - `TradeConfirmation`: The payload received from `/confirms/{dealReference}` or WS stream.
  </action>

  </verify>
