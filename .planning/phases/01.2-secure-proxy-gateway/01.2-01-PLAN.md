<objective>
Implement a granular, secure serverless proxy gateway on Vercel to resolve the CORS 'Catch-22' and ALPN negotiation failures blocking the frontend-backend handshake.

Purpose: 
1. Move Cloudflare Access token injection to the server-side (Vercel) to satisfy CORS preflight requirements.
2. Force HTTP/1.1 via `undici` to resolve ALPN errors with Cloudflare Tunnels.
3. Incorporate behavioral testing to ensure header preservation, body streaming, and error propagation are correctly implemented (Nyquist compliance).

Output:
- Shared proxy utility and granular serverless handlers.
- Refactored frontend client and cleanup of local proxying.
- Behavioral test suite in `api/proxy.test.ts`.
</objective>
