# Phase 01.2 Plan 01: Secure Proxy Gateway Summary

## Objective
Transform the Vercel gateway into a secure, production-first bridge to the GHA backend by hardening body handling and standardizing upstream routing.

## Key Changes
- **BACKEND_URL Integration**: The proxy now uses a mandatory `BACKEND_URL` environment variable for all upstream requests, removing legacy hardcoded Capital.com URLs and environment-switching logic.
- **ArrayBuffer Body Handling**: Updated `proxyRequest` to consume inbound request bodies as `ArrayBuffer` before forwarding. This prevents intermittent "Body is unusable" or 500 errors often seen when streaming bodies in Serverless functions.
- **StabilityTrace Logging**: Added structured logging with the `[StabilityTrace]` prefix for:
  - Proxying intent (method, path, target)
  - Upstream response status
  - Fatal configuration errors (missing `BACKEND_URL`)
- **Security Mitigations**:
  - Automatically strips `host`, `connection`, and `content-length` headers (T-01.2-01).
  - Injects Cloudflare Access Service Tokens if configured (T-01.2-02).
- **ALPN Fix Preservation**: Maintained `allowH2: false` in the shared `undici` Agent to ensure compatibility with Cloudflare Tunnels.
