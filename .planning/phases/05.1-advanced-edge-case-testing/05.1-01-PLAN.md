# Phase 05.1 Plan 01: Advanced Edge Case Testing

## Goal
Expand the E2E test suite built in Phase 5 to cover complex trading edge cases, including attached order cancellations, complex position trimming (half-flatten), and API error recovery.

## Requirements
- TEST-04: Test suite must cover edge cases for attached SL/TP pseudo-orders, `flattenHalfSymbol` leg assassination, and `executingOperations` lock recovery on API failures.

  <read_first>tests/e2e/advanced-edge-cases.spec.ts</read_first>
  <action>Create `tests/e2e/advanced-edge-cases.spec.ts`. Implement tests that place a market order, attach a Stop Loss and Take Profit, and then cancel the attached SL/TP.   </acceptance_criteria>
</task>
