# Phase 05.2 Plan 01: Data Stitching & Market Engine Validation

Provide a rigorous E2E test suite to validate the Market Data Engine built in Phase 2. This ensures that historical REST data and live WebSocket streams stitch together seamlessly, and that connection resilience handles network drops without data gaps or memory leaks.

## Requirements
- TEST-05: Test suite must validate seamless data stitching, WebSocket auto-reconnects, environment switching, and prevent subscription leaks.

## Tasks

<task>
  <id>1</id>
  <title>Test Seamless Data Stitching</title>
  <read_first>tests/e2e/market-data-stitching.spec.ts</read_first>
  <action>Create `tests/e2e/market-data-stitching.spec.ts`. Execute the test directly against the live demo endpoint without using local mocks. Assert that the chart state (`usePriceStore` or UI) correctly updates with live WebSocket ticks appended to the historical REST candles without any visual gaps or data duplication. Explicitly validate the gap tolerance requirement by asserting that the system throws a `DataStitchingError` or fails appropriately if the time gap between the last REST candle and the first WebSocket tick exceeds 1 second.</action>
  <acceptance_criteria>
    - Test executes against live demo endpoint without local mocks.
    - Test verifies UI handles live ticks seamlessly post-historical data.
    - Test validates gap tolerance, ensuring `DataStitchingError` is thrown if the gap > 1s.
  </acceptance_criteria>
</task>
