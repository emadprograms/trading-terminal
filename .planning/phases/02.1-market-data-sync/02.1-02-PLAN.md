# Plan: 02.1-02 - Hook Integration & Handover Logic

## Goal
Refactor `useChartData` to use the `SyncCoordinator` for a seamless data handover.

## Context
`useChartData` currently manages history and WS subscription independently. It needs to be the consumer of the coordinator's state machine.

## Implementation Details
1. **Refactor `useChartData`**:
   - Instead of direct `fetchMarketData`, call `SyncCoordinator.startSync(ticker, timeframe)`.
   - Observe the coordinator's data output to populate `localMasterData`.
2. **Error Handling**:
   - Ensure the hook handles sync timeouts or bridge fetch failures gracefully.

## Verification Plan
- Unit test `useChartData` with mocked coordinator.
- Manual verify that switching tickers triggers the full sync sequence.
