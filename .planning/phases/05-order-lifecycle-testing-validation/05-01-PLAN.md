# Phase 05 Plan 01: Live E2E Testing & Validation for Capital.com API

## Goal
Implement a live E2E testing framework to validate the Capital.com API integration. Bypassing mocks is critical because local mocks cannot replicate Capital.com's strict matching engine validations, which previously led to false positives where tests passed but the live system rejected payloads.

## Requirements
- TEST-LIVE-01: A dedicated test suite that runs against the live Capital.com Demo API using real credentials.
- TEST-LIVE-02: Tests must place real micro-orders and wait for the live WebSocket `confirms` event to verify acceptance.
- TEST-LIVE-03: The test must immediately close/flatten the position after validation.
- DOCS-TEST-01: Update testing documentation emphasizing the necessity of live API validation over local mocks for broker interactions.
