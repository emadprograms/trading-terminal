# Plan 05: Watchlist Sync Gap Closure

This plan addresses the blockers identified during UAT for Phase 06.

## Task 1: Fix Backend Proxy Configuration
- **File:** `vercel.json`
- **Action:** Add a rewrite rule for `/api/watchlist/:path*` mapping to `/api/watchlist`.
- **Details:** Place the rule before the catch-all `/(.*)` rule to ensure that requests with specific IDs (e.g., `/api/watchlist/123`) correctly hit the serverless proxy instead of returning a 405 Method Not Allowed error from `index.html`.

## Task 2: Implement Watchlist ID Tracking for Updates
- **File:** `src/store/useWatchlistStore.ts`
- **Action:** Update the state shape to include `remoteWatchlistId: string | null`.
- **Details:** When initializing or syncing the watchlist via `fetchWatchlist`, capture the ID from the Capital.com API payload (e.g., `data.watchlists[0].id` or `data.id`). Store this ID in the Zustand state, and throw an error if it's missing during `syncWithRemote`. Pass this ID to the `updateWatchlist` API call.

## Task 3: Update Watchlist Service to Forward IDs
- **File:** `src/services/watchlist.ts`
- **Action:** Update `updateWatchlist(symbols)` signature to `updateWatchlist(symbols: string[], id?: string | null)`.
- **Details:** If an `id` is provided, append it to the path (e.g. `watchlist/${id}`). This ensures the PUT request targets the specific watchlist record on Capital.com instead of hitting the generic collection endpoint (which results in 405).

## Task 4: Fix Watchlist Sync E2E Tests
- **File:** `tests/e2e/watchlist-sync.spec.ts`
- **Action:** Fix missing mock structures and payloads to match the API.
- **Details:** 
  - Mock all `**/api/watchlist*` requests in `beforeEach` to intercept and return fake data (e.g. `{ watchlists: [{ id: 'mock-123', epics: ['SPY', 'QQQ'] }] }`) for GET, and `{ success: true }` for PUT. This isolates the test from Capital.com auth errors.
  - Update any manual `fetch` calls in the test (like in `afterEach`) to use the correct Capital.com payload structure (`{ epics: symbols }` instead of `{ symbols }`).
