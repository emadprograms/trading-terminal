# Phase 03 Plan 01: Fix Chart Hover Price Indicator

## Goal
Replace the default crosshair price label (the dash) with an accurate price axis arrow label that displays the exact execution price when hovering over historical order markers on the chart.

## Requirements
- UI-01

## must_haves
- [ ] D-01: Hovering over a chart order triangle displays an arrow containing the exact order entry price, treating the incorrect price as a bug and resolving the coordinate mapping.
- [ ] D-02: The existing sideways arrow animation on the chart pane remains untouched, and no new features are added.
- [ ] D-03: Maintain the current price formatting for the entry price display.
- [ ] The default horizontal crosshair line and label are dynamically hidden while hovering over an execution.
- [ ] The default crosshair line and label are fully restored when the mouse moves off the marker.

## Artifacts this phase produces
- **Classes**: `TradeAxisView` in `src/lib/TradePlugin.ts`
- **Methods**: `priceAxisViews()` in `TradePlugin` class
- **Fields**: `price` property added to the `closestExec` object/type passed to `setHoveredExecutions`
