# Plan: 02-02 - WebSocket Real-time Engine

## Goal
Implement a high-performance WebSocket manager to stream real-time Bid/Ask ticks, updating the UI with sub-second latency.

## Context
The terminal needs "live" feeling price action. This requires a persistent WebSocket connection that synchronizes with the user's active tickers and account environment.

## Implementation Details

### 1. WebSocket Manager (`src/lib/ws-manager.ts`)
Create a singleton class or a store-managed service to handle the WebSocket lifecycle.
- **Connection Management:** 
    - Establish connection to `wss://.../connect` based on `useSessionStore.environment`.
    - Implement auto-reconnect logic with exponential backoff.
- **Authentication & Subscription:**
    - Upon connection, send the `marketData.subscribe` payload containing the `cst` and `securityToken` from the session store.
    - Maintain a set of active `epics` to subscribe/unsubscribe dynamically as the user changes tickers.
- **Message Dispatcher:**
    - Listen for `marketData.update` messages.
    - Dispatch updates to a Zustand store or a custom event emitter that the UI can observe.

### 2. Live Price Store (`src/store/usePriceStore.ts`)
Create a small, high-frequency store to hold the latest Bid/Ask for active tickers.
- `prices: Record<string, { bid: number, ask: number, timestamp: number }>`
- `updatePrice(epic, bid, ask, timestamp)`: Atomic update of the current price.

### 3. UI Integration
- **Price Display:** Update `ChartHeader` or a new `PriceTicker` component to observe `usePriceStore` and display the live Bid/Ask.
- **Chart Update:** Integrate the live tick into `useChartData` so that the most recent candle's close price updates in real-time.
- **Environment Sync:** Ensure that whenever `useSessionStore.environment` changes, the WebSocket manager closes the existing connection and reconnects to the correct environment endpoint.

## Verification Plan

### WebSocket Tests (`tests/unit/ws-manager.test.ts`)
- **Auth Flow:** Verify that the subscription message contains the correct tokens.
- **Subscription Logic:** Verify that adding a ticker to the workspace triggers a `marketData.subscribe` message.
- **Message Handling:** Mock a `marketData.update` server message and verify the `usePriceStore` is updated.

### Manual Validation

- Verify that the price in the header ticks in real-time.
