# Milestone v1.2 Roadmap

## Phase 1: Test-Driven Development (TDD) Foundation

**Goal:** Build a robust, bulletproof testing benchmark (Playwright & Unit) for the Netting Engine before implementing any code.
**Requirements:** HIST-04

- [x] Investigate raw activity history from Capital.com to understand partial close data structures.
- [x] Write Unit Tests for the Netting Engine that input mocked raw execution arrays (handling staggered entries, partial closes, and full exits) and assert the correct output `Trade` objects.
- [x] **Ensure Unit Tests specifically cover:** Missing ENTRY executions, explicit `action` fields (`ENTRY` vs `EXIT`), storing `entryPrice`, and correct P&L calculations.
