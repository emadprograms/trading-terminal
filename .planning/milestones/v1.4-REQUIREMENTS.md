# Requirements: Milestone v1.4 (Chart Alerts Integration)

### Chart Interaction

- [x] **CHART-01**: User can hover over the Y-axis of the chart to reveal a "plus" (+) symbol at the corresponding price level.
- [x] **CHART-02**: User can click the plus symbol to open the alert creation flow pre-filled with that price level.

### Visual State

- [x] **VISUAL-01**: Existing alerts for the current asset are visually plotted on the chart as horizontal lines.

### Test Coverage

- [x] **TEST-01**: Playwright E2E test verifies hovering over the Y-axis, clicking the plus icon, and successfully creating an alert.

## Future Requirements (Deferred)
